# alu-back-end

This project uses a REST API to gather data about employees and their TODO lists.

## api

- `0-gather_data_from_an_API.py`: a Python script that takes an employee ID as an argument and prints the employee's TODO list progress, including the titles of completed tasks.

### Usage

    python3 api/0-gather_data_from_an_API.py <employee_id>
